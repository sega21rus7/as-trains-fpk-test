# Hello World на React

Простой стартовый шаблон приложения на React, TypeScript и Vite. На главной странице отображается надпись «Hello World».

## Требования

- Node.js 22 или новее
- npm 10 или новее

## Установка

```bash
npm install
```

## Запуск для разработки

```bash
npm start
```

После запуска Vite откроет приложение в браузере.

## Доступные команды

- `npm run dev` — запустить сервер разработки.
- `npm run build` — проверить типы и собрать production-версию.
- `npm test` — запустить тесты Jest.
- `npm run test:coverage` — запустить тесты с отчётом о покрытии.
- `npm run lint` — проверить исходный код ESLint.
- `npm run lint:fix` — исправить найденные ESLint проблемы, где это возможно.
