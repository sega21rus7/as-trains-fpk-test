# Витрина туристских поездов

Одностраничное приложение на React и TypeScript с каталогом туристских поездов по России. Данные о пяти маршрутах загружаются из локального файла `trains.json` и проверяются перед отображением.

[Открыть приложение на GitHub Pages](https://sega21rus7.github.io/as-trains-fpk-test/)

## Возможности

- поиск по названию поезда;
- совместная фильтрация по региону и месяцу отправления;
- карточки с маршрутом, длительностью, ближайшей датой и стоимостью;
- подробное модальное окно со всеми датами, экскурсиями и тегами;
- адаптивный интерфейс для компьютера и телефона;
- доступное управление с клавиатуры и закрытие окна клавишей `Escape`.

Кнопка «Купить билет» ведёт на внешний сайт, указанный в `buy_url`, и открывает его в новой вкладке. Покупка внутри прототипа не выполняется.

## Требования

- Node.js 22 или новее;
- npm 10 или новее.

## Установка

```bash
npm ci
```

## Запуск для разработки

```bash
npm start
```

После запуска Vite откроет приложение в браузере. Если браузер не открылся автоматически, перейдите по адресу `http://127.0.0.1:5173/`.

## Доступные команды

- `npm run dev` — запустить сервер разработки;
- `npm run build` — проверить типы и собрать production-версию;
- `npm test` — запустить тесты Jest;
- `npm run test:coverage` — запустить тесты с отчётом о покрытии;
- `npm run lint` — проверить исходный код ESLint;
- `npm run lint:fix` — исправить доступные ESLint-проблемы.
